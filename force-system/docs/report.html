空间力系的简化与计算

工程力学课程编程作业

1. 题目与输入输出

编写程序，对任意空间力系向指定点进行简化，求主矢和主矩，并给出最终简化结果。若能简化为一个合力，需要确定合力作用线；若为力螺旋，需要确定中央轴及轴上保留的力偶矩。

输入包括各力的大小、方向、作用点和简化点。程序允许用分量直接输入力，也允许输入力的大小和任意非零方向向量。另外可以输入独立力偶矩。统一使用右手直角坐标系，长度用 m，力用 N，力矩用 N·m。

输出包括主矢、主矩的分量、大小、单位方向和方向角，以及最终简化类型、作用线或中央轴。零向量没有确定方向，此时输出“未定义”。

2.4 浮点数的判断

程序使用双精度浮点数，不能只用数值是否严格等于零来分类。力的判断阈值为 10⁻¹⁰ N 加 10⁻⁹ 倍各力大小之和；力矩阈值为 10⁻¹⁰ N·m 加 10⁻⁹ 倍各分力矩与独立力偶矩大小之和。判断是否为力螺旋时，比较主矩沿主矢方向的投影大小与力矩阈值。

输出保留计算得到的分量和实际使用的阈值。若输入量级接近容差，简化类型应理解为该精度下的结果。

3. 程序流程

计算内核 mechanics.py 负责向量运算与力系简化，main.py 提供命令行入口，gui.py 提供窗口输入，plotting.py 绘制原力系与简化结果并导出图片。两种交互方式使用同一套计算函数。

计算前检查向量是否为三个有限实数，方向向量是否为零，力的大小是否非负。输入不符合要求时给出提示，不继续使用错误数据。

4. 使用说明

运行环境为 Python 3.10 或以上版本及 Tkinter。力学计算内核只使用标准库，窗口中的三维绘图与图片导出使用 Matplotlib。在 force-system 目录先运行 python -m pip install -r requirements.txt，再运行 python gui.py。Windows 配置了 Python 文件关联时，也可双击 launch.pyw 启动。

左侧载荷区默认加载课堂算例，点击卡片编辑载荷，点击“+ 添加”增加力或独立力偶。作用力可用大小、方向向量和作用点输入，也可直接填写分量；窗口输入框支持 √2、sqrt(2) 和 1/6 等简单算式。修改简化点后，点击“计算并生成图像”更新结果。

主区域显示主矢和主矩的大小、分量与方向角，并排显示原力系与最终简化的三维图。拖动图像可以旋转查看，导出图片会保留当前视角。合力给出作用线，力螺旋给出中央轴、轴向力偶矩和螺距，逐项力矩与计算过程在右侧“运行细节”中展开。

点击“导出图片”，可保存带数值结果的高清 PNG 或矢量 SVG，内容包括原力系图、最终简化图、主矢和主矩、方向角以及作用线或中央轴。力和力矩分别按显示比例绘制，环形箭头按右手法则表示力偶矩。JSON 的打开和保存用于保留输入数据。

命令行不带参数时逐项输入；python main.py --example 直接运行课堂算例；--output result.json 保存数值结果；--image result.png 或 --image result.svg 导出结果图片。

6. 检查与适用范围

自动检查包含课堂算例和四种简化类型，并核对方向向量归一化、主矩换点公式、中央轴任一点的力矩重构及输入错误提示。在作业目录运行 python -m unittest discover -s tests -v。

本程序处理三维静力学集中力和力偶。平面力系是其特例；分布载荷需要先换算为等效集中力及力偶。程序的数值输出用于辅助计算，使用前仍需正确判断图中的力方向、作用点和单位。
