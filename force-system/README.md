# 空间力系的简化与计算

本项目实现空间力系向指定点的简化。输入各力的大小、方向、作用点及简化点，得到主矢和主矩的分量、大小与方向，并判断力系最终简化为平衡力系、合力、力偶或力螺旋。对于合力给出作用线，对于力螺旋给出中央轴、轴向力偶矩和螺距。

计算采用右手直角坐标系，通过各力的矢量和与对简化点的力矩和求得主矢、主矩，再依据两者及其数量积确定简化类型。程序支持力的分量输入、大小与方向向量输入，以及独立力偶矩输入，统一使用 m、N 和 N·m。

程序使用 Python 编写，计算部分只依赖标准库。命令行支持逐项输入和 JSON 算例读取，Tkinter 窗口支持载荷编辑、结果查看和固定斜投影示意，两种入口共用同一套计算函数。

项目附有边长为 1 m 的立方体算例及其计算报告，并通过平衡、合力、力偶、力螺旋和主矩换点等检查核对结果。[使用说明](docs/usage.md) 记录了运行方法与输入格式。
