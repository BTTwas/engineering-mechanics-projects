# 空间力系的简化与计算

工程力学课程编程作业。输入各力及简化点，求主矢、主矩，再判断力系能否继续简化。长度、力和力矩分别使用 m、N、N·m。

## 运行

需要 Python 3.10 或以上版本，不需要安装第三方包。窗口界面需要 Tkinter。

```bash
cd force-system
python gui.py
```

窗口默认载入课堂立方体算例。可以修改简化点，选中表格中的力后修改，或添加、删除力。力有两种输入方式：直接填三个分量，或填写大小和方向向量。方向向量不必是单位向量，例如 `0 -1 1`。独立力偶直接填矩的三个分量。

修改输入后点击“计算”。“计算结果”页给出主矢、主矩的分量、大小和方向角；“力系示意”页用固定斜投影显示各力和中央轴。示意图只辅助看方向，具体数值以计算结果为准。窗口可以打开和保存 JSON 算例。

没有 Tkinter 时可使用命令行：

```bash
python main.py
python main.py --example
python main.py --input examples/cube.json
python main.py --example --output result.json
```

第一条命令逐项询问简化点、各力和独立力偶。输入三个分量时用空格隔开；方向角输出为与 x、y、z 正轴的夹角，单位为度，零向量的方向不定义。

## 算例数据

以图中的 O 为原点，沿正方体棱建立右手坐标系，边长 1 m。

| 力 | 作用点 | 方向向量 | 大小 / N | 分量 / N |
| --- | --- | --- | --- | --- |
| F₁ | (1,0,0) | (0,0,1) | 1 | (0,0,1) |
| F₂ | (1,1,0) | (0,-1,1) | √2 | (0,-1,1) |
| F₃ | (0,1,0) | (0,-1,0) | 1 | (0,-1,0) |
| F₄ | (0,0,1) | (1,1,0) | √2 | (1,1,0) |

F₂ 在前侧面内，沿右下角指向左上角；F₄ 在顶面内，沿后左角指向前右角。按图中的箭头方向输入后，R = (1,-1,2) N，Mₒ = (0,-1,-1) N·m，最终简化为力螺旋。中央轴通过 (1/2,1/6,-1/6) m，平行于 (1,-1,2)，螺距为 -1/6 m。

## JSON 格式

`origin` 为简化点，`forces` 为各力，`couples` 为独立力偶矩。每个力选择“分量”或“大小加方向”一种写法，不能混用：

```json
{
  "origin": [0, 0, 0],
  "forces": [
    {"name": "F1", "point": [1, 0, 0], "components": [0, 0, 1]},
    {"name": "F2", "point": [1, 1, 0], "magnitude": 2, "direction": [0, -1, 1]}
  ],
  "couples": []
}
```

这里 F₂ 的大小为 2 N，只用于说明输入格式。课堂算例使用 `examples/cube.json` 中的 √2 N。没有独立力偶时填空数组；平面力系可令 z、Fz 为零。

## 检查

在本文件所在目录运行：

```bash
python -m unittest discover -s tests -v
```

覆盖课堂算例、平衡、合力、力偶、力螺旋、方向归一化、主矩换点和中央轴等效关系。程序对 NaN、无穷大、零方向向量和不完整输入报错。

数值判断使用绝对与相对容差。力、力矩的绝对容差分别为 10⁻¹⁰ N 和 10⁻¹⁰ N·m，相对容差为 10⁻⁹。结果中保留原始计算值，不把很小的非零量直接改成零。适用范围为三维静力学集中力和力偶；分布载荷需先等效为集中力及力偶。
