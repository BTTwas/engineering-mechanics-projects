# 工程力学课程项目

本仓库保存工程力学课程中的编程项目和计算资料，目前包含空间力系的简化与计算。

## 空间力系的简化与计算

根据各力的大小、方向、作用点和指定简化点，计算空间力系的主矢与主矩，并确定最终简化结果。程序能够区分平衡力系、合力、力偶和力螺旋，给出合力作用线或力螺旋的中央轴、轴向力偶矩及螺距。

项目使用 Python 编写，提供命令行和窗口两种交互方式。窗口通过载荷卡片输入数据，并排展示原力系与最终简化结果的三维图，计算细节在右侧展开。输入可保存为 JSON，计算结果可导出为 PNG 或 SVG 图片。

项目位于 [`force-system`](force-system) 目录，包含计算程序、立方体算例和计算报告。
