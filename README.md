# 工程力学课程项目
- JBK1300006
目前该仓库内容为***空间力系简化计算器***

本项目属于工程力学课程的个人编程实践，用来辅助学习，public作为学习记录与交流参考，后续有优化会进行逐步改善

## 简介

输入各力的大小、方向、作用点和指定简化点，计算空间力系的主矢与主矩，并确定最终简化结果。程序能够区分平衡力系、合力、力偶和力螺旋，给出合力作用线或力螺旋的中央轴、轴向力偶矩及螺距。（如果存在合力作用线或中央轴）

技术栈：
1. `Python`
2. `Tkinter` 窗口界面
3. `Matplotlib` 三维绘图

项目使用 Python 编写，提供命令行和窗口两种交互方式。可以通过窗口输入数据（支持添加、修改和删除），并排展示原力系与最终简化结果的三维图。所以它除了显示数值，还能对照查看原力系和化简后的力系，右侧可以展开计算细节。

输入可保存为 JSON，计算结果可导出为 PNG 或 SVG 图片。

**项目位于 [`force-system`](force-system) 目录，包含计算程序、立方体算例和计算报告。**
